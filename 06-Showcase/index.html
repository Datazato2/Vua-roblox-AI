🤖 Roblox之王 AI

帮助阅读文档、分析内容，并从英语视频中学习表达的 AI Agent

📌 一句话介绍：Roblox之王 AI 接收通过 Lark 发送的 Word、PDF 文档或视频链接，分析内容，并用越南语清晰呈现重点、论点、结论和词汇学习内容。

💡 这是什么？

Roblox之王 AI 是一款面向个人阅读与学习的 AI Agent。对于文档，它旨在通读内容、解释难懂概念、区分原文信息与解读，并总结主要含义。

对于英语视频，如果能够访问视频或 transcript，Agent 可以整理有用的单词和短语，并说明语境含义、用法、词性、IPA、估算 CEFR 等级以及时间戳（在数据允许时）。

Agent 帮助你理解和学习；重要信息仍应回到原始材料核对。

⏱️ 它能减少哪些工作？

任务以前现在可获得的帮助
阅读长文档自己通读并逐段做笔记生成结构化摘要
理解难懂概念自行查资料并梳理观点关系结合文档语境解释概念
寻找论点与结论反复查找相关段落区分核心观点、论据和原文结论
学习英语视频自行寻找 transcript 并查词在数据允许时整理词汇、用法和时间戳

📥 输入与输出

可提供的输入

  • 通过 Lark 发送的 Word 或 PDF 文件
  • 可进行 OCR 的扫描 PDF 或图片
  • 可访问的视频链接或 transcript
  • 具体要求：摘要、分析、概念解释或词汇学习

预期输出

  • 清晰易懂的越南语摘要
  • 结合语境解释难懂概念
  • 主题、论点、证据、结论与含义
  • 词汇表：用法、词性、IPA、估算 CEFR 等级及可用的时间戳

⚙️ 工作步骤

流程依据项目中的工作流文档。处理方式会随输入类型而变化。

1
必须接收用户通过 Lark 发送的文件或链接。
2
必须识别输入类型。Word/PDF/图片：提取文字，扫描件必要时使用 OCR。视频：在可访问时检查画面与音频，并生成 transcript。
3
必须确认内容可访问且足够清晰。如有问题，说明问题所在并请用户提供其他版本或补充信息；若仍不足，则停止处理无法完成的部分并说明限制。
4
必须分析主题、难懂概念、核心观点、论点、结论及其含义。
5
应该如果是英语视频，在证据充分时整理单词/短语、语境含义、用法、词性、估算 CEFR 等级、IPA 和时间戳。
6
必须用越南语撰写报告，并检查完整性、清晰度、依据和引用；未达标准时进行补充或修改。
7
必须通过 Lark 发送结果，并说明仍存在的限制或未验证之处。

🛡️ 规范与能力边界

Agent 应做到

  • 明确区分原文内容与解读
  • 说明不确定性和数据限制
  • 不编造页码、时间戳、引文或证据
  • 无法读取或内容模糊时请用户协助

Agent 不应做

  • 不替用户作出重要决定
  • 不把 OCR/ASR 结果说成绝对准确
  • 不擅自分享私人内容或执行未被要求的操作
  • 不保证所有链接或文件都能访问

🧪 输出示例

示例要求：“请阅读这份材料，解释难懂概念，并说明论点与结论。”

摘要：作者介绍了一个问题、支持其观点的理由以及最终结论。

原文论点：“……” （在能够确定时标注原文位置）

通俗解释：可以把这个观点理解为……

限制：现有数据或证据可能不足以确认因果关系。

说明：以上仅用于展示格式，不是对真实文件的分析结果。

🚀 如何使用

打开 Lark，找到已连接 Hermes 的机器人，然后发送 Word/PDF 文件或视频链接，并说明你希望它完成什么任务。

📨 示例消息：
“请通读这份材料，用越南语总结，解释难懂概念，列出论点和结论。请明确区分原文内容与解读，并说明任何限制。”

对于英语视频，也可以要求整理词汇表，包括语境含义、用法、词性、IPA、估算 CEFR 等级，以及 transcript 能支持的时间戳。

🛠️ 设计中使用的工具

Codex

用于创建和修改 Agent 的项目材料，例如 Job Card、Workflow、Profile 和介绍网页。

Hermes Agent

用于根据 Profile 运行 Agent 并处理任务。实际状态可能随设备配置而变化。

Lark / Feishu

用于发送请求并接收回复。已检查文字消息往返；文件访问取决于权限和配置。

DeepSeek

用于理解请求并生成 Agent 的回答内容。

⚠️ 使用提示

  • 请对照原文核实摘要和重要结论。
  • 扫描 PDF 或视频 transcript 可能存在 OCR/ASR 识别错误或遗漏。
  • Agent 只能读取当前账户和配置允许访问的材料。
  • 不要发送密码、API key、token 或不必要的私人信息。
  • 此展示页为静态介绍，不提供文件上传，也不能让访客调用真实 Agent。
